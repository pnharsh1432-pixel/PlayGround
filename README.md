## APEX / Night Run

A browser-based, endless 3D night racer. Serve this folder with any static web server and open it in a modern browser; Three.js is loaded from jsDelivr.

- **Steer:** A / D or ← / →
- **Nitro:** W / ↑ (or hold the mobile Nitro button)
- **Pause:** Esc or the Pause button
- **Goal:** dodge traffic, manage your hull (three hits end the run), and beat your best distance.
- Pick a car color on the title screen; touch steering and nitro controls appear on mobile.
